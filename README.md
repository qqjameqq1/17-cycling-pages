Visitors can browse sample routes and page introductions. My account, ride creation, member activities and personal actions require Google sign-in; first sign-in creates an account. New events default to private (owner only), with an explicit public option visible to signed-in members. Only the host can edit or cancel a published event. Routes, rides and private events remain private. Legacy browser records are retained without automatic upload. Firebase stays on the Spark plan; cloud operations require a network connection. Refresh the event list to see other members' changes.

Invite-based group rides support expiring/revocable invitations, registration, capacity limits, waitlists, cancellation and promotion. Group details require authorized membership; in-app updates appear after refresh. Existing private/member-visible event listings remain separate.
